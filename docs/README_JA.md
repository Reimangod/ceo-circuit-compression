# 全軌道CEO回路圧縮のコードとデータ

本Repositoryには, 現在索引化されている全軌道41条件の保存データと,
2026年10月31日の最新圧縮Policyを収録した. 最新Policyの実行範囲は
LiH 8条件, HF 2条件, BeH₂ 8条件, N₂ 4条件の計22条件であり,
各条件に3つの出発回路を設けた66試行であった.
41条件はこの22条件を含む. 残る条件や旧版の試行を最新Policyの性能へ加算する扱いとは区別した.

## 使い方

最初にルートのREADMEの手順で固定版のデータを取得し, `tools/verify.py`を実行する.
`tools/reconstruct_census.py`は保存データの結合を再実行し, 41条件の数値と比較関係を照合する.
`tools/reproduce.py`は保存結果から表と図を生成する. いずれも新しい分子探索を起動しない.

`report/CEO_full_orbital_policy.docx`は既存の改訂済みWordを変更せず収録した.
表の由来列と平均削減率の説明は省いたままとし, 原記録への対応は機械可読データに保持した.

## 全軌道の範囲

LiH 12条件, HF 2条件, BeH₂ 12条件, N₂ 4条件, H₄ 2条件,
H₆ 7条件, H₈ 2条件を収録した. 結合長, 全座標, 電子数, 基底,
量子ビット数は`data/tables/conditions.csv`で確認できる.
H₈は6-31Gの32量子ビットであり, 最新Policyの小規模分子実験とは別の保存資料であった.
全軌道判定は, 原子組成から得た全電子数, 基底の全軌道数, 凍結軌道設定を照合した.
混合ファイルは全軌道部分を抽出し, 元ファイルのハッシュと抽出情報を残した.

## 比較と費用

比較には同じ物理問題の実在するCEO保存点を用い,
`E_child <= E_CEO + 1e-9 Ha`の関係を確認した.
資源の4指標は一組の実回路から取得し, 指標ごとの別回路の最良値を合成しない.
元分解から共通簡約による減少と, 構造探索による追加の減少を分けた.

費用Wはエネルギー評価回数とスカラー勾配成分評価回数の換算量であり,
`W = N_energy + 2 N_scalar_gradient_components`であった.
実機ショット数, 測定グループを用いるCEO論文のMeasurement Costとは区別する.
最新圧縮探索の117,745 W, 事前照合77 W, 追加照合24 Wは別項目として保持した.
元CEOの生成費用は別であり, 未記録の値を0で補完していない.

## データの読み方

原回路の収束, 出力の停留性, 比較元からのエネルギー非悪化,
基底状態に対する絶対精度は別の属性である.
最新66試行の`MODEL_CAP_TERMINAL`は登録した費用上限での終端を表す.
全試行の収束成功を意味する名称として用いない.
旧版の欠測, 部分的な認証, 深さが増加した代替案も区別して保存した.

今回の保存資料からは, 同じ追加費用で成長継続したCEOへの優位性や,
実機雑音下の利益, 未知分子への一般化までを一括して主張しない.

## 原資料と権利

原研究領域は変更せず, 公開用の派生資料を別に作成した.
元データの採否・数値・未知値の意味を保持し, 再利用イベントを新しい評価へ加算しない.
上流CEOコードの固定commitとApache-2.0を維持し, 自作データ・説明書にはCC BY 4.0を指定した.
個人メール, 認証情報, 商用フォント本体, 学習モデルは収録対象から外した.
Private状態で保存し, Public化やDOI付きの公開は別の操作として扱う.
