# 全軌道CEO回路への統一圧縮Policyの適用

2026-10-31。全軌道ソース索引の22条件を対象に、各軌跡の成長反復数の1/3切上げ・2/3切上げ・最終を出発点とする。全66入力を結果取得前に固定する。旧12条件の凍結内殻版、既存の全軌道10条件、新規全軌道ソースは改変しない。

## 維持する科学的規則

v19の候補生成、共通回路簡約、候補初期順位、最大256初期評価、1本の待ち行列、8回のエネルギー・勾配同時評価ごとのBFGS配分、最大100同時評価/構造、受理点に結び付く逆Hessian再利用、数値許容差、採否規則を維持する。過去の圧縮回路・削除位置・成功係数・学習器を入力にしない。候補生成の元は未圧縮のCEO記録のみ。

入力別上限は従来と同じ B=2F+128+20(1+2P) W。FはHFを含む元保存点数、Pは出発回路の独立係数数。W=N_energy+2*N_scalar_gradient_components。128は基本予算枠で、初期評価上限256とは別である。プール勾配は圧縮で再測定しない。元CEO生成費用は圧縮費用に加算せず別に扱う。実機ショットや原論文のgrouped Measurement Costと同一とは主張しない。

比較元CEOと候補へ同じ既知初期状態に基づく回路簡約を適用する。E_child <= E_raw_CEO + 1e-9 Ha と、共通簡約後の比較CEO以下のCNOT深さを満たす候補からCNOT数、全深さ、独立係数数、エネルギーの順に一つを選ぶ。元分解からの総削減と共通簡約後の追加削減を分ける。開始回路自身との比較と、全途中回路との比較を分ける。正の微小エネルギー差も保存する。無改善を成功件数へ数えない。

## 実装の対応

1. 最大ブロック数を全入力共通で64から96へ拡張する。根の部分列候補生成上限4095、全保存点からの1/2削除、登録MVP→OVP拘束は同じ規則である。
2. 全分子共通で、指定粒子数・スピン別電子数の全配置を保持する厳密部分空間の計算を使う。状態の振幅・配置の切り捨ては行わない。
3. 入力Pauli Hamiltonianを同じビット反転ごとに合算してから部分空間の疎行列を構成する。元の係数を閾値で削除しない。これによりN2の大量の重複三重項の実体化を避ける。回路は元のCEOの素ゲートのまま、局所行列で作用させる。
4. 勾配計算には粒子数を保存する元CEOブロックを使う。状態準備だけの等価性を持つ簡約回路を、任意入力で等価なユニタリとして逆伝播しない。
5. 独立認証ではQiskitが構成した局所ゲート行列から状態を再構成し、別のPauli項別期待値経路でエネルギーを計算する。資源は実際のQiskit回路から再計数する。数値計算部分の資格試験では小分子の全Qiskit状態・エネルギー・勾配と照合する。最終の出発点比較出力には全Qiskit状態ベクトルによる追加照合を行う。この追加検証の古典時間を探索時間と分ける。

今回の変更は数値バックエンドと実行可能な回路サイズであり、v19と実行軌跡がビット単位で一致する保証ではない。小さい勾配や順位の数値縮退で選択が分岐する可能性は保存する。

## 安全性と完了

1数値worker、BLAS1、600秒/入力、外側の強制期限780秒、RSS目安1.5 GiB、出力上限1 GiB、ディスク空き512 MiB。候補構築中にも時間・メモリを確認する。過去研究を読めないsandboxを使い、通信を禁止する。自動延長・自動再試行・削除・GPU・FCI・学習・外部送信を行わない。中断した入力を完了や無改善へ置き換えない。

全66終端、費用台帳照合、元ソースハッシュ保持、資源とエネルギーの比較表・保存回路・全係数・欠測理由を納品する。削減を保証するのではなく、条件を満たしたと検証できた出力だけを圧縮成功とする。
